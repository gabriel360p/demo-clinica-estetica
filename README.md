## 📌 Sobre o projeto



O **Demo Clínica Estética Belezza** é uma landing page institucional desenvolvida para representar uma clínica de estética moderna, apresentando seus serviços, diferenciais e informações importantes para seus clientes.



O projeto foi criado simulando uma solução digital para um negócio real do segmento de beleza e estética, com foco em transmitir profissionalismo, confiança e uma identidade visual alinhada ao mercado.



A aplicação foi desenvolvida utilizando tecnologias fundamentais da Web, explorando boas práticas de estruturação HTML, estilização CSS e interações através de JavaScript.



---



## 🎯 Objetivos do projeto



- Criar uma presença digital profissional para uma clínica de estética;

- Desenvolver uma interface moderna voltada para apresentação de serviços;

- Aplicar conceitos de UI/UX em uma solução comercial;

- Criar uma experiência responsiva para diferentes dispositivos;

- Praticar desenvolvimento de páginas próximas às necessidades reais do mercado.

## 🧩 Organização do projeto



A aplicação foi organizada utilizando uma estrutura tradicional de desenvolvimento Web, separando responsabilidades entre marcação, estilos e scripts.



Exemplo:



```
src

├── index.html

├── css

│   └── style.css

│

├── js

│   └── script.js

│
```



Essa organização facilita a manutenção do código e permite futuras evoluções do projeto.
